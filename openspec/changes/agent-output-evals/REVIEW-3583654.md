## Non-blocking observation: a noisy answer scores the same as a clean one

`{"directives":[SKILL, GOTO×5]}` passes with `detail={'n': 6, 'skill': 1}`. That is
defensible — extra well-formed directives are not malformed, and `n` records the
count — but the prompt asks for "exactly ONE directive of kind SKILL", so an answer
that does not obey is scored identically to one that does. If the baseline is meant
to measure *adherence*, a strict variant (`n == 1` when a SKILL is present) would
separate them. Flagging, not requiring: the current rule matches what the spec says
and the `n` field makes the difference visible in the report.
