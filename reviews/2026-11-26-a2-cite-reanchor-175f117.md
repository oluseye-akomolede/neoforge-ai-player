## FINDING — `spec.md:1480` is false, and always has been

Left alone as "base-relative, currently true". It is neither.

The sentence (`spec.md:1478-1481`) reads: "before this change the only case that
unbound (`_unbind_planner_script` at the `done` close, `agent.py:1259` at this
change's base commit)."

- **`agent.py:1259` is not `_unbind_planner_script` at any rev the sentence has
  existed.** At `389a658` and `9ce7018` it is `if self._bind_planner_script(...)`;
  at `af2b8e6` and `8a75994` it is `inv_context = self._get_my_inventory_summary()`.
  It has never been the unbind call.
- **The real `done`-close site is `agent.py:1393`** (`_unbind_planner_script()`,
  immediately after `_complete_task_board_task()`; `:1421` is the failure path and
  its own comment says "only the `done` close unbinds"). It is `:689` at
  `389a658`/`9ce7018` and `:697` at `af2b8e6`/`8a75994` for the *reset* path, which
  is a different site.
- "Base commit" is never named, so "currently true" is unfalsifiable as written —
  and on every candidate base it is in fact false.

**Fix:** name the site by symbol, not line — "the `_unbind_planner_script()` call
at the `done` close (the one after `_complete_task_board_task()`)" — which is the
same rule the rest of this commit applies.
